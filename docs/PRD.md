## 1. Executive Summary（执行摘要）

KOCopilot 是面向**普通 KOC（独立内容创作者）**的一套**轻量级 AI Agent 工作流**，通过将顶尖 MCN 机构的"爆款拆解—人设定位—长尾分发—互动运营"四大核心能力封装为**操作极简**的系统功能，帮助单打独斗的创作者跨越系统性运营鸿沟。

产品采用 **"用户上传爆款视频 → ASR 模态降维 → DeepSeek 文本解析 → 引导式协同创作"** 的核心技术链路，使用户在不具备编导思维与数据分析能力的情况下，也能产出结构严密的原创脚本、定位精准的差异化人设、覆盖长尾搜索的元数据包装，以及高质量的评论区互动回复。

> **一句话定位**：让一个人，干出一个 MCN 团队的产出质量。

## 2. Problem Statement（问题陈述）

### 2.1 问题归属：谁有这个问题？

普通独立 KOC 创作者，特征：
- **资源约束**：无团队、无编导、无运营，单人完成全链路；
- **专业断层**：缺乏内容方法论（不懂 Hook 公式、节奏铺垫、CTA 设计）与数据分析能力；
- **平台依赖**：依靠抖音 / 小红书 / B站 / 视频号等算法分发平台获客与变现；
- **变现脆弱**：粉丝量级 1k–50w，处于"商业化萌芽—初步变现"阶段，对账号增长高度敏感。

### 2.2 问题本质：三大"死亡螺旋"

> 以下三条来自产品方原始素材，是本 PRD 的核心立论依据。

#### 痛点 1：选题与创作极度低效 ⭐ 核心痛点

- **现象**：面对空白文档存在严重"创作焦虑"；能刷到爆款但**看不懂**爆款。
- **根因**：缺乏"编导思维"——无法拆解爆款的 Hook（黄金前 3 秒）、叙事节奏、情绪铺垫、CTA 话术。
- **后果**：自身产出的脚本平庸、完播率极低，进入"产出—低播放—失去信心—减少更新"的负循环。

#### 痛点 2：内容定位与商业化模糊

- **现象**：盲目跟风宽泛赛道（如"泛美妆"、"泛生活"）。
- **根因**：缺乏数据分析能力与差异化定位方法论。
- **后果**：人设辨识度低、与海量同质账号陷入红海竞争、广告主无法识别价值。

#### 痛点 3：分发与互动运营不专业

- **现象**：发布时标题随意、标签混乱、评论区放任不管。
- **根因**：创作环节已耗尽精力 → "运营降级"。
- **后果**：错失平台长尾搜索流量（SEO）、互动率指标失分（算法核心权重之一）、账号热度衰减加速。

### 2.3 问题证据 [假设 - 待补真实数据]

> 当前 v1 PRD 暂以行业常识陈述。**强烈建议**产品方在评审前补充：用户访谈引用、平台数据样本、竞品功能对比表。

- 行业认知：抖音/小红书等平台头部 5% 创作者占据 80%+ 流量（长尾效应）；
- 行业认知：单视频前 3 秒决定 50%+ 完播率（"黄金 Hook 法则"）；
- 待补：来自 N 位目标用户的访谈记录，验证"创作焦虑—不知如何拆解爆款"为最强痛点。

### 2.4 为什么痛？影响量化 [假设]

| 影响维度 | 当前状态 | 量化后果 |
|---|---|---|
| 用户层面 | 无方法论指导 | 单条视频从选题到成片耗时 6–10 小时；产出 5 条爆款 1 条；账号月增粉 <500 |
| 业务层面 | 服务空白 | KOC 在创作工具领域既不是"剪映"（剪辑工具）也不是"新榜"（数据工具）的目标用户，缺乏一站式 AI 副驾解决方案 |

## 3. Target Users & Personas（目标用户与画像）

### 3.1 主用户画像：成长期独立 KOC「小美」

| 维度 | 描述 |
|---|---|
| 身份 | 上班族 / 自由职业者 / 全职妈妈，副业内容创作者 |
| 平台 | 抖音 / 小红书 / 视频号（至少其一为主战场） |
| 粉丝量级 | 1k – 5w |
| 创作领域 | 平价好物分享、职场干货、宝妈生活、轻知识科普等垂类 |
| 创作频次 | 1–3 条/周 |
| 工具栈现状 | 剪映（剪辑）+ 微信收藏夹（灵感）+ Excel 表格（粗记录） |
| 技术能力 | 中等：会用 SaaS、不会写代码、理解"标签""话题"等平台基础概念 |
| 商业化阶段 | 处于「积累粉丝 → 接零星广告」过渡期，月广告收入 0–5000 元 |
| 核心 JTBD（Jobs-to-be-done） | "当我刷到一条爆款，我想立刻拆解它的成功公式，然后用我自己的人设和素材做出一条同样能爆的内容——但不要复制粘贴，要原创且符合我的风格。" |

### 3.2 次要画像：决策探索期新人「小白」

- 量级：粉丝 < 1k，刚起步 1–3 个月；
- 痛点：连"做什么内容方向"都没想清楚；
- 与主用户差异：模块二（人设罗盘）使用频率更高，模块一/三/四使用门槛较高。

### 3.3 排除画像（非目标用户）

| 排除人群 | 原因 |
|---|---|
| MCN 机构内的专业编导 | 已有方法论，需要的是协作工具不是 AI 副驾 |
| 头部 KOL（>50w 粉） | 已有团队支持，工具化需求低 |
| 纯文字博主 / 直播达人 | 当前产品技术链路（视频→ASR→脚本）不匹配 |
| 平台官方运营 | 需要的是后台数据 API 而非创作工具 |

## 4. Strategic Context（战略上下文）

### 4.1 业务目标 [假设 - 待与产品方对齐]

- **北极星指标候选**：周活创作者数（WAC）×（人均产出脚本数 + 人均使用模块数）；
- **业务假设**：KOC 在"创作流程"环节单点付费意愿强（脚本即产能），优于"全包月卡"模式；
- **变现路径**（按可行性排序）：
  1. **付费抵扣制**：免费用户每月 N 次拆解额度，超出按次付费（最低门槛获客）；
  2. **会员订阅**：按月/年订阅解锁全模块 + 不限次数；
  3. **B 端授权**：向中小型 MCN 机构输出 API 或白标版本（远期）。

### 4.2 市场机会 [假设 - 待 TAM/SAM/SOM 调研]

- **TAM**：抖音/小红书/视频号等平台累计活跃创作者 [待补]；
- **SAM**：粉丝 1k–50w 区间的成长期创作者（约占活跃创作者的 [待补]%）；
- **SOM**：本产品 v1 阶段聚焦于以中文短视频为主、对工具付费意愿较高的创作者群体。

### 4.3 竞争格局 [假设 - 待补竞品对照表]

| 类别 | 代表 | 与 KOCopilot 差异 |
|---|---|---|
| 数据分析平台 | 新榜、蝉妈妈、灰豚 | 偏数据观察，不直接产出脚本与素材包装 |
| AI 写作工具 | 通用 LLM（豆包、ChatGPT）+ 通用提示词 | 缺乏垂类工作流封装，用户需自学 prompt |
| 剪辑工具 AI | 剪映 AI 文案 / 字幕 | 偏制作环节，不解决"选题与脚本骨架" |
| 国外类比 | TubeBuddy、VidIQ | 偏 YouTube SEO，不做爆款骨架拆解 |

**差异化定位**：本产品是**"创作者上游的智能副驾"**——介于"数据洞察工具"与"内容制作工具"之间的方法论封装层，竞争位空白且高频刚需。

### 4.4 为什么是现在？

- **AI 能力成熟拐点**：DeepSeek 等高性价比国产大模型 + Whisper 级开源 ASR，使产品成本结构具备可行性；
- **创作者经济进入下半场**：流量红利消退，从"勤奋者赢"转向"方法论者赢"；
- **平台算法 SEO 化**：标签/话题/搜索流量的权重持续抬升，元数据优化变成刚需。

## 5. Solution Overview（解决方案总览） ⭐ 核心功能 + AI 能力 + 交互流程

### 5.1 产品总体形态

KOCopilot 是一个**网页端工作台**（v1 形态），用户通过浏览器登录后，使用四个核心模块组成的端到端创作工作流。无需安装客户端、无需对接平台 API（规避平台合规风险）。

**信息架构**：
```
首页 (Dashboard)
├─ 模块一：爆款拆解工坊      （创作主入口）
│  └─ 上传视频 → 拆解结果 → 引导式脚本生成 → 导出
├─ 模块二：人设定向罗盘      （用户冷启动 / 阶段性复盘）
│  └─ 输入背景 → RAG 检索 → 人设方案
├─ 模块三：标题与标签车间    （脚本完成后的发布前一步）
│  └─ 输入脚本 → 生成 5 标题 + 简介 + 标签矩阵
└─ 模块四：评论分拣副驾      （视频发布后的运营环节）
   └─ 粘贴评论 → AI 过滤分类 → 三种语气回复草案
```

### 5.2 核心模块一：爆款逆向拆解与"脚手架"脚本引擎 ⭐ 技术亮点

#### 5.2.1 价值主张
将用户对标的爆款视频「降维」成可学习、可填空、可个性化复用的**脚本骨架**，从根本上解决"创作焦虑"。

#### 5.2.2 技术链路（暗箱处理）

```
[用户操作]                    [系统暗箱]                            [产出]
1. 上传 MP4 视频     ──►  服务端接收并存储到对象存储
                          ↓
2. （等待中）        ──►  调用 ASR 模型（Whisper 系列）抽帧/抽音轨
                          ↓
                          输出带时间戳的台词文本（VTT/SRT 格式）
                          ↓
                          调用 DeepSeek，prompt 为「专业短视频拆解分析师」
                          ↓
                          输出结构化骨架 JSON（Hook/Body/CTA + 时序）
                          ↓
3. 看到拆解报告     ◄──   渲染骨架到前端
                          ↓
4. 进入引导式问答   ──►  DeepSeek 基于骨架 + 用户人设上下文，
                          逐步生成填空提问
                          ↓
5. 用户回答问题     ──►  DeepSeek 综合骨架与回答，
                          生成完整分镜脚本
                          ↓
6. 导出脚本         ◄──   Markdown / Word / 复制纯文本
```

#### 5.2.3 爆款骨架定义（DeepSeek 输出 schema）

| 字段 | 类型 | 说明 |
|---|---|---|
| `hook_strategy` | enum | 钩子类型：痛点前置 / 反常识陈述 / 悬念提问 / 视觉冲击 / 身份认同 / 数字罗列 |
| `hook_text` | string | 原视频前 3 秒台词原文 |
| `hook_explanation` | string | 钩子设计原理与可迁移方法论 |
| `narrative_beats` | array | 叙事节奏数组（每段含起止时间、内容主题、情绪曲线） |
| `emotional_arc` | array | 情绪铺垫曲线（如：好奇→共鸣→反转→认同） |
| `cta_strategy` | enum | CTA 类型：点赞收藏 / 评论区留言 / 关注追更 / 引导私域 |
| `cta_text` | string | 原视频 CTA 话术原文 |
| `transferable_template` | string | 可复用模板（保留结构，去除原内容） |

#### 5.2.4 引导式问答示例

> 系统："原视频在第 5 秒用了一个『职场反常识观点』作为 Hook（"加班越多升得越慢"）。结合你的『平价好物分享』人设，你想用哪个『消费反常识』作为钩子？例如：
> A. 价格越便宜的护肤品成分反而更纯净
> B. 大牌口红的实际使用频率远低于平价
> C. 自己输入"

#### 5.2.5 验收要点（部分摘录，详见 §7）
- 上传支持格式：MP4 / MOV，单文件 ≤ 200MB（v1 限制）；
- 90% 拆解结果在 90 秒内返回；
- 引导式问答最少 3 轮、最多 7 轮，超过 7 轮强制收敛；
- 最终脚本 ≥ 200 字、含至少 1 个 Hook 段、1 个 CTA 段。

### 5.3 核心模块二：RAG 驱动的人设定向罗盘

#### 5.3.1 价值主张
让用户摆脱"泛美妆/泛生活"的同质化定位，找到**高辨识度、低竞争、易变现**的精准垂类人设。

#### 5.3.2 技术链路

```
[用户输入]
- 职业背景：行政文员，3 年经验
- 兴趣：日常做饭、二手收纳
- 可用资源：每周 2 晚 + 1 个完整周末

   ↓ DeepSeek 改写为检索查询

[RAG 检索]
检索内置「高转化 KOC 成功案例」向量库（v1 阶段约 [假设] 500–1000 条）
返回 Top-K 相似案例（K=5），含：人设描述、垂类、起号路径、变现方式

   ↓ DeepSeek 综合推导

[输出方案]
- 推荐人设 1：「打工人月薪 8k 的精致冰箱整理术」
  - 差异化：把「收纳」x「冰箱」x「打工人预算」三层叠加
  - 参考案例：xxx 账号
  - 起号建议：前 10 条聚焦「冰箱开箱 + 周末囤货预算」
  - 变现预判：与生鲜/收纳品牌契合度高

- 推荐人设 2：……（共 3 个备选方案）
```

#### 5.3.3 向量库初始化策略 [需技术评审]
- v1 由产品团队人工精选并标注 500–1000 条高转化案例；
- 嵌入模型采用 BGE-M3 或同等中文优化模型；
- 长期方案：建立众包补录通道，社区贡献新案例并人工审核。

### 5.4 核心模块三：长尾流量 SEO 与元数据包装

#### 5.4.1 价值主张
解决创作者"创作完已无力做发布"的运营降级问题，把发布前最后 30 分钟的工作压缩到 30 秒。

#### 5.4.2 技术链路

```
[用户输入]
- 模块一刚生成的脚本（自动带入）或粘贴自有脚本
- 选择平台：抖音 / 小红书 / 视频号 / B站 [v1 至少支持抖音 + 小红书]

   ↓ DeepSeek 提取脚本核心信息（主题、关键词、情绪、人群）

[输出包]
1. 5 个备选标题（不同钩子风格各一）
   ① 反常识型：「90% 的人冰箱都用错了」
   ② 数字型：「3 招让冰箱大 1 倍」
   ③ 身份型：「打工人的省钱式冰箱整理」
   ④ 痛点型：「冰箱总是塞不下？因为你没做这一步」
   ⑤ 悬念型：「我重新整理冰箱后，每月省了 800 元」

2. 视频简介（120 字内，富含搜索关键词）

3. 标签矩阵（"泛流量词 + 精准长尾词"双层结构）
   - 泛流量层：#收纳 #生活技巧 #打工人
   - 精准长尾层：#冰箱整理 #小户型冰箱 #预算冰箱囤货
```

#### 5.4.3 平台差异化适配 [产品规则]
- 抖音：标题强 Hook、标签数量适中；
- 小红书：标题带 emoji、关键词前置（搜索权重）；
- 视频号：偏自然语句、避免营销味；
- B 站：标题信息密度高、可使用书名号。

### 5.5 核心模块四：高价值评论分拣与互动副驾

#### 5.5.1 价值主张
从"评论区是负担"变成"评论区是杠杆"——让创作者在不调用平台 API 的合规前提下，10 分钟内完成原本需要 1 小时的优质回复运营。

#### 5.5.2 技术链路

```
[用户操作]
1. 在平台 App 中复制视频底部的评论文本（可一次性复制 50–200 条）
2. 粘贴到 KOCopilot 工作台的"评论分拣"区

   ↓ DeepSeek 分类（不联网、不调用平台 API）

[分类结果]
- 高价值层（默认展示）
  - 干货提问：5 条，含原文 + 提问点
  - 争议探讨：3 条
  - 高互动潜力：2 条（带情绪/共鸣点）
- 中价值层（折叠）
  - 一般评论：12 条
- 低价值层（折叠）
  - 灌水/无意义："支持"、"好看"等：N 条（默认隐藏）

   ↓ 用户点击某条高价值评论

[三种语气回复草案]
- 专业解读：「关于你提到的 X 问题，可以从 A、B、C 三个角度看……」
- 幽默调侃：「哈哈哈这个问题让我笑出声 + 一句反差金句」
- 共情安抚：「我太懂这种感受了……（共情）+ 提供方向」

   ↓ 用户选择一条 → 一键复制 → 粘贴回平台
```

#### 5.5.3 合规说明 [关键]
**全程仅做纯文本辅助，绝不调用平台 API、不直接发布、不读取用户的平台账号。** 这是产品长期可持续的合规底线。

### 5.6 AI 能力总览（独立专章，对应用户要求第 3 项）

| 能力层 | 模型/技术 | 用途 | 替代方案 |
|---|---|---|---|
| ASR 语音转写 | Whisper 系列（v3 / large-v3） | 视频音轨 → 带时间戳台词 | 阿里 Paraformer / 讯飞 |
| 大模型推理 | DeepSeek（V2 / V3） | 骨架拆解、引导问答、脚本/标题/标签生成、评论分类与回复 | OpenAI GPT-4o / 通义 / 豆包 |
| 嵌入模型 | BGE-M3（中文优化） | 模块二人设案例向量化与检索 | M3E / OpenAI text-embedding-3-large |
| 向量数据库 | Qdrant / Milvus（v1 选其一） | 案例库存储与相似检索 | Pinecone（云）/ pgvector（轻量） |
| Prompt 工程 | 系统级 prompt 模板库 + 用户上下文注入 | 保证各模块输出稳定结构 | 自研 |
| 安全护栏 | 内容审核中间层 | 过滤涉黄涉政、避免 PII 泄露 | 第三方审核 API |

**AI 能力的产品级原则**：
1. **可解释**：每个 AI 输出附带「为什么这样建议」的简短理由（例如人设方案的差异化解释）；
2. **可控**：用户能改、能拒、能再生成（不强迫接受）；
3. **可降级**：模型异常时给出"返回简化版结果 + 提示重试"，不直接报错；
4. **可观测**：服务端记录每次调用的 token 数、耗时、模型版本，用于成本与质量监控（不记录用户原始内容）。

## 6. Success Metrics（成功度量）

### 6.1 北极星指标（候选，待对齐）

> **周内功能闭环率（WFCR）= 周内完成至少 1 次「模块一→模块三」端到端创作的用户数 / 周活创作者数**

理由：单独使用任一模块说明产品工具属性强，但**端到端闭环**才说明真正用我们解决了完整问题。

### 6.2 主要指标（v1 上线 30 天考察）

| 指标 | 当前基线 | v1 30天目标 | 90 天目标 |
|---|---|---|---|
| 周活创作者数（WAC） | 0 | [假设] 500 | [假设] 3000 |
| 模块一拆解任务完成率 | — | ≥ 85% | ≥ 90% |
| 模块一脚本最终导出率 | — | ≥ 60% | ≥ 75% |
| 周内功能闭环率（WFCR） | — | ≥ 25% | ≥ 40% |
| 用户每周平均产出脚本数 | — | ≥ 1.5 条 | ≥ 3 条 |
| 付费转化率（轻付费/会员） | — | ≥ 3% | ≥ 8% |

### 6.3 体验/质量指标

- 模块一 ASR 准确率（中文清晰口播） ≥ 90%；
- 模块一拆解结果"可用率"（用户标记为"有帮助"） ≥ 70%；
- 平均拆解耗时（视频 ≤ 3min）≤ 90 秒。

### 6.4 护栏指标（不应变差）

- 系统级错误率 ≤ 1%；
- LLM 调用平均成本 / 拆解任务 ≤ [假设] 0.30 元；
- 用户隐私事故数 = 0（红线）。

## 7. User Stories & Requirements（用户故事与需求）

### 7.1 Epic 假设

> 我们相信，**为成长期独立 KOC 提供"上传爆款视频 → AI 拆解骨架 → 引导填空生成原创脚本 → 一键生成发布元数据 → 评论区智能回复"的端到端 AI 副驾**，能够将其单条视频的产出耗时从 6–10 小时缩短至 1–2 小时，并将其爆款命中率从 1/5 提升到 1/3，理由是当前痛点的核心是"方法论缺失"而非"工具缺失"——而方法论可以被 AI 工作流封装。我们将通过「周内功能闭环率（WFCR）」与「用户脚本导出率」在上线 30/90 天后验证这一假设。

### 7.2 用户故事（节选关键 8 个，详细列表移至 `docs/user-stories.md`）

#### S-1：上传爆款视频并查看拆解
作为一名成长期 KOC，我想上传一个对标的爆款 MP4 视频，自动得到它的 Hook / 节奏 / CTA 拆解报告，这样我就能快速理解它为什么爆。

**验收标准**：
- [ ] 支持 MP4 / MOV，单文件 ≤ 200MB；
- [ ] 上传过程显示进度，可取消；
- [ ] 90% 任务在 90 秒内返回结果；
- [ ] 失败时给出明确原因（音频缺失/格式不支持/服务繁忙）并支持一键重试；
- [ ] 拆解报告至少包含 hook_strategy、narrative_beats、cta_strategy 三段。

#### S-2：基于骨架进入引导式问答
作为一名 KOC，我想被 AI 一步步引导生成属于我自己人设的脚本，而不是被丢一份空白模板，这样我就不会创作焦虑。

**验收标准**：
- [ ] 引导轮次 3–7 轮；
- [ ] 每轮提供 2–3 个建议选项 + "自由输入"通道；
- [ ] 任意一轮可后退 / 跳过 / 终止；
- [ ] 最终生成的脚本与骨架结构对应，且去除了原视频内容关键词。

#### S-3：导出最终脚本
作为一名 KOC，我想把生成的脚本导出为 Markdown / 复制到剪贴板 / 推送到下一模块，这样我可以在任何工具继续工作。

**验收标准**：
- [ ] 三种导出方式至少支持其中两种；
- [ ] 脚本带分镜分段（场景 / 台词 / 画面建议）。

#### S-4：基于个人背景获得人设方案
作为一名新人 KOC（小白），我想输入我的职业、兴趣、可用资源，得到 3 个差异化人设方案，这样我不再迷茫到底做什么内容。

**验收标准**：
- [ ] 输入字段最多 3 项，每项不强制必填；
- [ ] 返回 3 个方案，每个含人设名 / 差异化逻辑 / 参考案例 / 起号建议 / 变现预判；
- [ ] 用户可"换一批"重新生成（最多 3 次/天）。

#### S-5：为脚本生成发布元数据
作为一名 KOC，我想把刚生成的脚本一键转换成发布所需的标题/简介/标签，这样我不再因为运营降级流失流量。

**验收标准**：
- [ ] 标题 5 个，覆盖至少 3 种钩子风格；
- [ ] 简介 ≤ 120 字，含 ≥ 3 个搜索关键词；
- [ ] 标签矩阵：泛流量 ≥ 3 个、精准长尾 ≥ 5 个；
- [ ] 支持选择目标平台并差异化适配。

#### S-6：批量分拣评论
作为一名 KOC，我想粘贴视频下方所有评论，让 AI 帮我过滤出值得认真回复的那些，这样我把时间花在高 ROI 互动上。

**验收标准**：
- [ ] 支持单次粘贴 50–200 条；
- [ ] 输出三层分类（高价值/中价值/低价值），高价值默认展开；
- [ ] 高价值评论标注分类标签（提问/争议/共鸣）。

#### S-7：为评论生成三种语气的回复草案
作为一名 KOC，我想得到 3 种不同语气的回复草案，这样我能根据当时心情和账号调性选用。

**验收标准**：
- [ ] 三种语气：专业 / 幽默 / 共情；
- [ ] 每条草案 ≤ 150 字；
- [ ] 一键复制后给出"已复制，请到平台粘贴"的提示。

#### S-8：账号与历史记录
作为一名 KOC，我想能看到我过去 30 天的所有拆解任务、生成脚本、人设方案，这样我可以复用与对比。

**验收标准**：
- [ ] 拆解任务、脚本、人设方案三类历史均可访问；
- [ ] 支持按时间倒序、按关键词搜索；
- [ ] 用户可主动删除任意一条。

### 7.3 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 模块一 P90 ≤ 90 秒、模块二/三/四 P90 ≤ 15 秒 |
| 可用性 | 月度可用性 ≥ 99.5% |
| 安全 | 用户上传视频在拆解后 24h 内自动删除（仅保留拆解结果文本） |
| 隐私 | 不调用任何平台 API；评论文本仅用于本次会话，不入向量库 |
| 可观测 | 服务端记录调用链（trace_id）、模型版本、token 消耗、错误码 |
| 国际化 | v1 仅中文；架构层预留多语种接口（不做本地化） |
| 设备 | v1 优先桌面浏览器（Chrome / Edge），移动端阅读可用、操作降级 |

## 8. Out of Scope（明确不做）

| 项 | 暂不做的原因 |
|---|---|
| 直接对接抖音/小红书/视频号官方发布 API | 平台合规风险高、维护成本巨大；先做纯文本辅助验证模式 |
| 自动剪辑、自动配音、自动配乐 | 偏制作环节，已有剪映/CapCut 等成熟工具；本产品聚焦"上游脑力" |
| 多人协作 / 团队工作台 | 主用户为独立创作者，多人协作非高频；商业化阶段再评估 |
| 数据看板（粉丝/播放/转化分析） | 平台数据需爬取或第三方接入，复杂度高；先聚焦"创作—发布"闭环 |
| 直播脚本 / 直播运营辅助 | 直播场景与短视频差异大，独立产品线 |
| 海外平台（YouTube / TikTok / Instagram）支持 | v1 优先中文短视频生态，海外延后 |
| 用户自定义 prompt / 角色 | v1 强工作流封装，避免用户陷入"调 prompt"的复杂度 |
| 本地部署 / 私有化版本 | 个人用户无此需求；远期考虑 B 端授权时再做 |

## 9. Dependencies & Risks（依赖与风险）

### 9.1 技术依赖
- DeepSeek API 服务稳定性（建议同时保留 1 个备用模型供应商以做降级）；
- Whisper / Paraformer ASR 服务（推荐自建容器化服务以控成本）；
- 向量数据库 Qdrant 或 Milvus 部署；
- 对象存储（视频临时存储 + 24h 自动清理）；
- CDN（前端静态资源）。

### 9.2 内容依赖
- 模块二的"高转化 KOC 成功案例"向量库需要内容运营人工精选 500–1000 条（v1 上线前必须完成）；
- 各模块的 prompt 模板需经过专业内容运营/资深 KOC 顾问校验。

### 9.3 风险与缓解

| 风险 | 严重度 | 缓解策略 |
|---|---|---|
| 用户上传视频涉版权问题 | 高 | 用户协议明确"仅用于个人学习与分析"；24h 自动删除；不留存视频原文件 |
| 用户上传违法违规内容 | 高 | 接入第三方审核 API；ASR 后做关键词敏感词过滤 |
| LLM 输出不稳定（结构错乱） | 中 | 严格 JSON Schema 约束 + 服务端校验 + 失败重试；前端降级展示 |
| LLM 成本超预期 | 中 | 调用前估算 token、超长输入分段、启用缓存、对免费用户限额 |
| ASR 在背景音乐大或方言情况下识别差 | 中 | 错误率 > 阈值时引导用户手动粘贴台词 |
| 用户对"AI 生成的脚本不算自己原创"产生顾虑 | 中 | 模块一强调"AI 引导用户填空"而非"AI 替写"；导出脚本注明"由你与 AI 协同创作" |
| 平台政策变化（如禁止 AI 内容） | 中 | 不在产品中宣称"完全 AI 生成"；强调用户主导 |
| 数据隐私事故（用户视频/评论泄露） | 极高 | 端到端加密传输；最小权限存储；24h TTL；定期渗透测试 |
